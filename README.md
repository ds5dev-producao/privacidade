# Políticas de Privacidade

Páginas públicas com a política de privacidade de cada cliente que usa o cashback e as mensagens por WhatsApp da DS5. A Meta exige essa URL para publicar o app da WhatsApp Cloud API.

Publicadas pelo GitHub Pages (branch `main`, pasta raiz):

| Cliente | URL |
|---|---|
| Rutra Menswear | https://ds5dev-producao.github.io/privacidade/rutra/ |

Para incluir um cliente, copie a pasta `rutra/`, ajuste nome, CNPJ, endereço e contato, e adicione o link no `index.html`.
